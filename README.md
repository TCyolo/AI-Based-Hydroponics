AI-Based Hydroponics System

This project is a hydroponics monitoring system that uses an ESP32 to collect sensor data such as temperature, humidity, and moisture levels. 
The project also includes a Python-based AI model and a simple web dashboard for working with and displaying the collected data.

The main goal of the project is to combine IoT and AI to make monitoring a hydroponics setup easier and more data-driven.

Hardware: ESP32, DHT11, Moisture Sensor, Relay, Water Pump, LED
Technologies: Arduino/C++, Python, Machine Learning, HTML, CSV

AI tools were used for research, code assistance, debugging, and development.
